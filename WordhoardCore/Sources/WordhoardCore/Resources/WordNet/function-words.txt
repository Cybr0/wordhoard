# Closed-class English function words: always model-only in "WordNet + model" mode
# (issue #11, decision 3). WordNet is useless or misleading for these (no prepositions
# or conjunctions at all; "despite" is only an archaic noun; "however" has adverb senses
# with unusable glosses), while the model-only senses call handled "however" perfectly.
#
# One lemma per line, lowercase; multi-word lemmas with single spaces; "#" starts a
# comment. Matched against the normalised headword (trimmed, lowercased, single spaces),
# so "May" the month also lands here — accepted.
#
# Not on the list on purpose: content words with a minor function use (like, past,
# round, well, need, little, half, one) and numerals. "gaslight" is not a function word:
# it stays on the WordNet path with its noun sense (known gap, see README).
